# Многокритериальный выбор методом ЭЛЕКТРА

**Цель работы:** Изучение эффективности применения метода ЭЛЕКТРА для поддержки принятия решений в производственно-технологических задачах при наличии множества противоречивых критериев.

## Описание задачи

Предприятие предполагает заключить договор о поставках железной руды с одним из шести возможных поставщиков. Выбор осложняется тем, что альтернативы имеют различные качественные и количественные характеристики, которые противоречат друг другу (например, более качественная руда может стоить дороже). 

**Задача:** Оценить поставщиков по набору заданных критериев с учетом их важности, отсеять заведомо неэффективные варианты (найти множество Парето), рассчитать веса критериев на основе мнений экспертов (метод ранга) и определить оптимальных поставщиков (сформировать «ядро» альтернатив) с помощью вычисления индексов согласия и несогласия по методу ЭЛЕКТРА.

## Исходные данные (Задание 6)

В соответствии с индивидуальным вариантом (Задание 6) выбор осуществляется из шести поставщиков (П1 – П6) по трем критериям:
* **Содержание металла в руде, %** (направление оптимизации: максимизация).
* **Стоимость руды, ден.ед./тонну** (направление оптимизации: минимизация).
* **Надежность поставок** (направление оптимизации: максимизация). Качественные оценки переведены в числовые значения по шкале Харрингтона («возможны нарушения» = 0.36, «достаточно высокая» = 0.63, «высокая» = 0.8, «очень высокая» = 1.0).

Важность критериев оценивается двумя независимыми экспертами:
* **Эксперт 1:** 1-е место — Содержание металла; 2-е место — Надежность поставок; 3-е место — Стоимость руды
* **Эксперт 2:** 1-е место — Содержание металла; 2-е место — Стоимость руды; 3-е место — Надежность поставок

## Архитектура программного комплекса

Приложение разработано на языке Python с использованием модульной архитектуры (MVC), жестко разделяющей данные, математические вычисления и графический интерфейс:

1. **`data.py` (Хранилище данных конфигурации)**
   Содержит исходные структуры данных. Включает списки поставщиков с числовыми значениями характеристик (с учетом преобразования Харрингтона), массив направлений оптимизации (1 для максимизации, -1 для минимизации) и матрицу рангов экспертов для последующего расчета весов.

2. **`model.py` (Бизнес-логика и моделирование)**
   Ядро математической обработки, реализующее несколько этапов принятия решений:
   * Нормализация оценок к единому диапазону [0;1]
   * Выделение множества Парето-оптимальных решений путем отбрасывания доминируемых альтернатив
   * Вычисление весовых коэффициентов каждого критерия методом ранга на основе матрицы экспертов
   * Реализация алгоритма ЭЛЕКТРА: расчет матриц согласия ($c_{jk}$) и несогласия ($d_{jk}$), а также поиск ядра альтернатив на основе заданных пороговых значений.

3. **`app.py` (Графический интерфейс пользователя - GUI)**
   Полноценное настольное приложение на базе библиотек **CustomTkinter** и **Matplotlib**. Состоит из следующих элементов:
   * **Боковая панель управления:** Отображает рассчитанные веса критериев и содержит интерактивные ползунки для динамической регулировки порогов согласия ($c^*$) и несогласия ($d^*$).
   * **Таблица результатов:** Подробная таблица, в которой выводятся статусы альтернатив (Парето/Ядро) и вычисленные индексы, с автоматической цветовой подсветкой лучших поставщиков.
   * **Графический анализ (Scatter plot):** Встроенная визуализация, отображающая альтернативы в координатах индексов согласия и несогласия. Показывает динамически изменяемую «оптимальную зону» (зеленую область ядра), позволяя наглядно оценить позиции всех поставщиков.

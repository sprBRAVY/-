# Базы знаний и поддержка принятия решений (БЗиОПР)

Данный репозиторий содержит программные комплексы, разработанные в рамках лабораторного практикума по дисциплине «Базы знаний и поддержка принятия решений» для студентов специальности «Информационные системы и технологии»[cite: 3]. 

## Структура репозитория

Для удобства навигации и изоляции проектов каждая лабораторная работа располагается в собственной независимой ветке (branch) данного репозитория:
* Ветка `main` содержит базовую информацию о проекте.
* Ветка `lab1` содержит реализацию лабораторной работы по методу Монте-Карло.
* Последующие ветки (`lab2`, `lab3` и т.д.) будут содержать соответствующие программные решения для других практических задач курса.

Для просмотра исходного кода конкретной работы необходимо переключиться на соответствующую ветку в интерфейсе GitHub или в локальном Git-клиенте.

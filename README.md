# Распознавание объектов в экспертных системах

**Цель работы:** Изучение методов и алгоритмов распознавания, применяемых в экспертных системах (ЭС), а также программная реализация и сравнительный анализ решающих функций на основе метода минимального расстояния и алгоритма восприятия (перцептрона).

## Описание задачи и теоретическая база

Системы распознавания предназначены для отнесения объекта к одному из известных классов на основе его признаков (вектора $X = (X_1, X_2, \dots, X_N)$). В данной работе реализовано два классических метода машинного обучения для построения решающих функций:

1. **Метод минимального расстояния:**
   Применяется, когда для каждого класса можно выделить характерный объект-прототип (центр масс класса). Решающая функция имеет вид:
   $D_i = 2 \cdot \sum(X_j \cdot P_{ij}) - \sum(P_{ij}^2)$
   Объект относится к тому классу, для которого значение $D_i$ максимально (что геометрически соответствует минимальному евклидову расстоянию до прототипа).

2. **Алгоритм восприятия (Перцептрон):**
   Строит линейную разделяющую границу (гиперплоскость) между двумя классами. Функция имеет вид:
   $D_{12} = W_1 \cdot X_1 + W_2 \cdot X_2 + \dots + W_N \cdot X_N + W_0$
   Обучение происходит итеративно: веса ($W$) корректируются каждый раз, когда алгоритм допускает ошибку на объекте из обучающей выборки, до тех пор, пока все объекты не будут распознаваться безошибочно.

## Исходные данные (`data.py`)

Данные представляют собой структурированную обучающую выборку, состоящую из **12 объектов**, разделенных на **2 класса** (по 6 объектов в каждом). Каждый объект описывается вектором из **5 числовых признаков** (от $X_1$ до $X_5$), значения которых нормализованы в диапазоне от 0 до 1.

*   **Класс 1 (условно «Крупные объекты»):** Характеризуется высокими значениями признаков (в основном от $0.7$ до $0.9$).
*   **Класс 2 (условно «Мелкие объекты»):** Характеризуется низкими значениями признаков (в основном от $0.1$ до $0.3$).

Такое распределение делает классы *линейно разделимыми*, что гарантирует успешную сходимость алгоритма восприятия за конечное число итераций.

Также в данных предусмотрены тестовые объекты (`TEST_OBJ_1` и `TEST_OBJ_2`), которые имитируют ввод пользователя по умолчанию для быстрой проверки работоспособности системы.

### 1. `models.py` (Бизнес-логика и моделирование)

Ядро математической обработки, содержащее реализацию алгоритмов классификации.

**Класс `MinDistanceClassifier` (Модель минимального расстояния)**
Отвечает за расчет прототипов классов и вычисление близости новых объектов к этим прототипам.

```python
class MinDistanceClassifier:
    def __init__(self):
        # Векторы-прототипы для первого и второго классов
        self.p1 = None
        self.p2 = None

    def fit(self, X, y):
        # Обучение сводится к нахождению математического ожидания 
        # (среднего значения) признаков для каждого класса.
        class_1_objs = X[y == 1]
        class_2_objs = X[y == 2]
        self.p1 = np.mean(class_1_objs, axis=0) # Прототип 1 класса
        self.p2 = np.mean(class_2_objs, axis=0) # Прототип 2 класса

    def predict(self, x):
        # Распознавание объекта: расчет решающей функции Di для каждого прототипа
        # D = 2 * (X скалярно на P) - (P скалярно на P)
        d1 = 2 * np.dot(x, self.p1) - np.dot(self.p1, self.p1)
        d2 = 2 * np.dot(x, self.p2) - np.dot(self.p2, self.p2)
        
        # Относим к классу с максимальным значением функции
        predicted_class = 1 if d1 > d2 else 2
        return predicted_class, d1, d2
```

**Класс `PerceptronClassifier` (Модель алгоритма восприятия)**
Реализует итеративное обучение линейного классификатора с коррекцией ошибки.

```python
class PerceptronClassifier:
    def __init__(self):
        # Массив весов (W) и порог (W0)
        self.w = None
        self.w0 = 0

    def fit(self, X, y):
        # Инициализация весов нулями
        self.w = np.zeros(X.shape[1])
        self.w0 = 0
        E = 0 # Счетчик правильно распознанных подряд объектов
        iterations = 0 # Общий счетчик итераций
        i = 0
        
        # Цикл работает, пока не будут правильно распознаны все объекты подряд
        while E < len(X) and iterations < 10000:
            x_obj = X[i % len(X)]
            target = y[i % len(X)]
            
            # Вычисление значения разделяющей функции
            d12 = np.dot(self.w, x_obj) + self.w0
            
            # Коррекция весов при ошибке распознавания
            if target == 1 and d12 <= 0:
                self.w += x_obj  # Смещение границы в сторону класса 1
                self.w0 += 1
                E = 0
            elif target == 2 and d12 >= 0:
                self.w -= x_obj  # Смещение границы в сторону класса 2
                self.w0 -= 1
                E = 0
            else:
                E += 1 # Объект распознан верно
                
            i += 1; iterations += 1
        return iterations

    def predict(self, x):
        # Применение найденных весов к новому объекту
        d12 = np.dot(self.w, np.array(x)) + self.w0
        predicted_class = 1 if d12 > 0 else 2
        return predicted_class, d12
```
